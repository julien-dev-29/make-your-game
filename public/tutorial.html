You will recreate the exact game in this repo: a single-player Bomberman on a 15×13 pillar grid, keyboard-only, with bombs, wandering enemies, pause menu, HUD (time / score / lives / FPS) and a requestAnimationFrame engine. Each step has code to copy, a test to prove it works, and a checkbox.

✅ What you’ll end up with

  • Hold-to-walk movement (150 ms per cell, no key spam)
  • Cross-shaped bombs, crates, chain reactions
  • Pause / restart, score, 3 lives, win & game-over screens
  • Only 2 DOM layers, transform-only motion → 60 FPS

📦 What you need

  • Node 20+, this repo, ~2 hours
  • Basic TypeScript + DOM (div, classes, events)

Step 1 — Input: held keys + edge triggers

Files: src/input/input.ts (+ create src/input/input.spec.ts) · 15 min
MODIFY src/input/input.tsCREATE src/input/input.spec.ts

Movement must keep working while a key is held (no spam-clicking). Bombs and pause must fire once per press (edge trigger). So we keep two things: a Set of held move codes, and one-shot queued flags for Space / P / Enter.

2. Minimal implementation

const MOVE_CODES = new Set([
  "ArrowUp","ArrowDown","ArrowLeft","ArrowRight",
  "KeyW","KeyA","KeyS","KeyD",
]);
const HANDLED = new Set([...MOVE_CODES, "Space","KeyP","Escape","Enter"]);

export function createInput() {
  const pressedKeys = new Set<string>();
  let lastDirection: string | null = null;
  let bombQueued = false, pauseQueued = false, confirmQueued = false;

  const down = (e: KeyboardEvent) => {
    if (!HANDLED.has(e.code)) return;
    e.preventDefault();            // stop page scroll on arrows/space
    if (e.repeat) return;          // ignore OS key-repeat for edge triggers
    if (MOVE_CODES.has(e.code)) { pressedKeys.add(e.code); lastDirection = e.code; }
    if (e.code === "Space") bombQueued = true;
    if (e.code === "KeyP" || e.code === "Escape") pauseQueued = true;
    if (e.code === "Enter") confirmQueued = true;
  };
  const up = (e: KeyboardEvent) => {
    if (MOVE_CODES.has(e.code)) {
      pressedKeys.delete(e.code);
      if (lastDirection === e.code) {
        const rest = [...pressedKeys];
        lastDirection = rest.length ? rest[rest.length - 1] : null;
      }
    }
  };
  window.addEventListener("keydown", down);
  window.addEventListener("keyup", up);
  return {
    pressedKeys,
    get lastDirection() { return lastDirection; },
    consumeBomb() { const b = bombQueued; bombQueued = false; return b; },
    consumePause() { const p = pauseQueued; pauseQueued = false; return p; },
    consumeConfirm() { const c = confirmQueued; confirmQueued = false; return c; },
    destroy() {
      window.removeEventListener("keydown", down);
      window.removeEventListener("keyup", up);
    },
  };
}

The base map is the classic pillar maze (walls every 2 cells). buildLevel1Grid() returns a fresh copy each call (so restart is trivial), scatters crates on alternating cells, then clears a safe zone around spawn (1,1):

export function buildLevel1Grid(): number[][] {
  const grid = BASE.map((r) => [...r]); // deep copy one row at a time
  grid.forEach((row, y) => row.forEach((v, x) => {
    if (v === 0 && (x + y) % 2 === 1) grid[y][x] = 1; // crates
  }));
  [[1,1],[2,1],[1,2]].forEach(([x, y]) => { grid[y][x] = 0; }); // safe zone
  return grid;
}

Gameboard owns that mutable copy and answers the only two questions gameplay needs:

export class Gameboard {
  constructor(private _grid: number[][]) {}
  get grid() { return this._grid; }
  inBounds(x: number, y: number) {
    return y >= 0 && y < this._grid.length && x >= 0 && x < this._grid[0].length;
  }
  isWalkable(x: number, y: number) {
    return this.inBounds(x, y) && this._grid[y][x] === 0;
  }
  destroyAt(x: number, y: number) { // crate -> floor, returns true if destroyed
    if (!this.inBounds(x, y) || this._grid[y][x] !== 1) return false;
    this._grid[y][x] = 0;
    return true;
  }
}

Step 3 — Player: grid-step with cooldown

Files: src/player/player.ts · src/player/player.spec.ts · 20 min

No pixel physics: the player lives on integer cells and steps one cell per 150 ms while a direction is held. Last-pressed direction wins, walls cancel the step (but still consume the cooldown, so holding into a wall doesn’t teleport later).

const DIRS: Record<string, { dx: number; dy: number }> = {
  ArrowUp: { dx: 0, dy: -1 }, KeyW: { dx: 0, dy: -1 },
  ArrowDown: { dx: 0, dy: 1 }, KeyS: { dx: 0, dy: 1 },
  ArrowLeft: { dx: -1, dy: 0 }, KeyA: { dx: -1, dy: 0 },
  ArrowRight: { dx: 1, dy: 0 }, KeyD: { dx: 1, dy: 0 },
};

export class Player {
  static STEP_MS = 150;
  private _cooldown = 0;
  constructor(private _name: string, private _position: { x: number; y: number }) {}
  get position() { return this._position; }
  reset(x: number, y: number) { this._position = { x, y }; this._cooldown = 0; }

  tryStep(code: string, board: { isWalkable(x: number, y: number): boolean }) {
    const d = DIRS[code];
    if (!d) return false;
    const nx = this._position.x + d.dx, ny = this._position.y + d.dy;
    if (!board.isWalkable(nx, ny)) return false;
    this._position = { x: nx, y: ny };
    return true;
  }
  update(dtMs: number, board: { isWalkable(x: number, y: number): boolean },
         input: { pressedKeys: Set<string>; lastDirection: string | null }) {
    this._cooldown -= dtMs;
    const code = input.lastDirection && input.pressedKeys.has(input.lastDirection)
      ? input.lastDirection
      : [...input.pressedKeys].pop() ?? null;
    if (!code || this._cooldown > 0) return false;
    const moved = this.tryStep(code, board);
    this._cooldown = Player.STEP_MS;
    return moved;
  }
}

Bombs: cross blast, blocked by walls, stops at first crate

export function computeBlast(grid: number[][], sx: number, sy: number, range: number) {
  const cells = [{ x: sx, y: sy }];
  const destroyed: { x: number; y: number }[] = [];
  const dirs = [[1,0],[-1,0],[0,1],[0,-1]];
  for (const [dx, dy] of dirs) {
    for (let i = 1; i <= range; i++) {
      const x = sx + dx * i, y = sy + dy * i;
      const v = grid[y]?.[x];
      if (v === undefined || v === 2) break;  // wall or outside: stop
      cells.push({ x, y });
      if (v === 1) { destroyed.push({ x, y }); break; } // crate: destroy, stop
    }
  }
  return { cells, destroyed };
}

Step 5 — Engine: rAF loop, fixed-step, states, scoring

Files: src/game/game-engine.ts (+ game-engine.spec.ts) · 30 min

One requestAnimationFrame loop drives everything. Logic runs on a fixed 120 Hz accumulator (stable on 60 Hz and 120 Hz+ screens), rendering happens every frame. dt is clamped to 50 ms so a tab-switch doesn’t tunnel through walls.

type GameState = "menu" | "playing" | "paused" | "gameover" | "win";

private loop(t: number) {
  if (this.destroyed) return;
  const dt = Math.min(t - this.last, 50); // clamp
  this.last = t;
  if (this.state === "playing") {
    this.acc += dt;
    const STEP = 1000 / 120;
    while (this.acc >= STEP) { this.tick(STEP); this.acc -= STEP; }
    this.timeMs += dt;
  }
  this.render();           // every rAF, even when paused
  this.fpsEma = this.fpsEma * 0.95 + (1000 / Math.max(dt, 1)) * 0.05;
  requestAnimationFrame((tt) => this.loop(tt));
}

private tick(stepMs: number) {
  player.update(stepMs, board, input);
  if (input.consumeBomb()) bombs.place(player.position.x, player.position.y);
  if (input.consumePause()) this.pause();
  const { score, hitCells } = bombs.update(stepMs, board);
  enemies.forEach((e) => e.update(stepMs, board));
  this.collisions(hitCells); // crates +50, enemies +200, player hit -> lives--
  // win: no crates and no enemies left -> +500, state = "win"
  // lose: lives 0 -> state = "gameover"
}

Step 6 — Render + HUD: 2 layers, transform-only, 60 FPS

Files: src/render/renderGameboard.ts · src/style.css · src/main.ts · 30 min

Exactly 2 layers: (1) a static board of 195 cells built once, (2) an absolutely-positioned entity layer. Per frame we only toggle classes on changed cells and move entities with transform + opacity (compositor-only, no layout).

/* static layer: build once */
export function renderGameboard(grid: number[][]) {
  const root = document.createElement("div");
  root.id = "static-layer";
  const cells: HTMLDivElement[] = [];
  grid.flat().forEach((v) => {
    const c = document.createElement("div");
    c.className = "cell" + (v === 2 ? " wall" : v === 1 ? " crate" : " floor");
    root.appendChild(c); cells.push(c);
  });
  function sync(next: number[][]) { // dirty-cell update only
    next.flat().forEach((v, i) => {
      const want = v === 2 ? "wall" : v === 1 ? "crate" : "floor";
      if (!cells[i].classList.contains(want)) {
        cells[i].classList.remove("wall", "crate", "floor");
        cells[i].classList.add(want);
      }
    });
  }
  return { root, sync };
}

Step 7 — Playtest, measure, go further

Manual QA + ideas · 15 min

Playtest checklist

  • Hold each arrow: smooth stepping, no spam needed; walls block.
  • Space near a crate: cross blast (range 2), crate → floor, +50.
  • Enemy touches blast → +200; enemy touches you → life lost, 2 s invulnerability, respawn at (1,1).
  • P pauses (overlay, FPS keeps running, no frame drops); Enter/R restarts cleanly.
  • DevTools → Performance: record 10 s, confirm ~60 FPS, no layout thrash; enable paint flashing — only entities should repaint.

Ideas to go further (pick one)

  • 🔥 Power-ups: range+1 or extra bomb slot hidden under crates.
  • 👾 Second enemy type: faster (250 ms) but only horizontal.
  • 📱 Touch controls: swipe = held direction, tap = bomb.
  • 🔊 WebAudio bleeps: place / explode / hurt / win (no assets needed).
